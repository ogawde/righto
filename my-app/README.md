# RightsTrack (Next.js)

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Add environment variables in `.env`:

```bash
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
RESEND_API_KEY=...
CRON_SECRET=...
```

3. Start development server:

```bash
npm run dev
```
